# UI/UX Guidelines

- **Favicon:** bright green letter **M** inside a gear. (Simple SVG recommended; can be swapped later.)
- **Dev route:** `/dev/step` keeps examples, Apply, Clear.
- **Trace:** human-friendly rule labels + rationale bullets.
- **Interactivity:** hover/selection colors (green/yellow/red), right-click info panel, quick actions, Undo/Redo, Auto-run.
- **Keyboard:** Ctrl+Enter (Apply), Esc (Clear). Optional arrow navigation when safe.
- **Accessibility:** semantic buttons, visible focus, test ids for render tests.
