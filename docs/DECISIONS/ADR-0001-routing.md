# ADR-0001: Flat Routes without react-router-dom

**Context.** В веб-пакете страницы представлены как независимые компоненты,
расположенные в `src/routes/**`. Маршрутизация  через прямые ссылки.
Это уже используется в `/dev`, `/dev/step`, `/demo/highlight`.

**Decision.**
- Не подключаем react-router-dom до появления чёткой необходимости.
- Новые страницы добавляются как отдельные компоненты + ссылка с хаба `/dev`.
- Для наглядности создадим `/dev/map` и `docs/ROUTING.md`.

**Consequences.**
- Меньше магии, проще вход новичкам.
- Эксперименты UI не ломают общий каркас.
- При росте числа страниц можно переоценить и перейти на явный роутер.
