# Motor docs

## Running the MicroViewer demo locally

1. Install dependencies if you have not already:
   ```bash
   pnpm install
   ```
2. Start the web dev server:
   ```bash
   pnpm dev:web
   ```
3. Open `http://localhost:5173/micro` in your browser. You should see the MicroViewer page with KaTeX samples and interactive bracket pairing.

Use the selector at the top of the page to switch between the provided examples. Hover or focus any bracket to highlight its partner and verify that pairing works as expected.
