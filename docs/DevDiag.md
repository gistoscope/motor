# /dev/diag — страница само-проверок

Страница доступна при запуске демо-сервера (`pnpm run diag` → http://localhost:4000/dev/diag).
Она открывает Playground в `<iframe>` и автоматически проверяет базовые сценарии.

## Что проверяется
- **Anchors** — в KaTeX-рендере должно быть как минимум три элемента с `id` (используются для привязок).
- **Hover** — при синтетическом наведении на токен должен появиться класс `.math-token--hovered`.
- **Click / Brackets** — пока помечены как `PENDING` и появятся после CC08.

Если проверка завершилась успешно, рядом появится зелёный бейдж `OK`.
Красный `FAIL` означает, что условие не выполнено; детали смотри в консоли браузера.

## Когда использовать
- Перед отправкой PR, чтобы убедиться, что базовые сценарии работают.
- При локальной разработке визуальных/интерактивных функций Playground.

## Как откатить
Удалите файл `packages/web/demo/dev/diag.html`, запись в `package.json` и роут в `packages/web/demo/server.mjs`.
