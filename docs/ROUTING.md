# Routing (packages/web)

## Важно
В проекте **нет** react-router-dom. Каждая страница  самостоятельный компонент
под `src/routes/**`, на неё ведёт прямая ссылка `<a href="/...">`.

## Из коробки
- `/dev`             индекс/hub, показывает Motor Dev / Tools are enabled и ссылки
- `/dev/step`        dev-экран TSA (StepDevRoute)
- `/demo/highlight`  демо подсветки (HighlightDemoRoute)

## Добавление новой страницы
1) Создать папку/файл под `src/routes/.../index.tsx` (или именованный файл .tsx).
2) Добавить **ссылку** на новую страницу на удобный хаб (обычно `/dev`).
3) Прогнать `pnpm verify` локально (типизация), затем `pnpm -C packages/web dev`.

## Почему так
- Минимум магии, легко читать и дебажить.
- Эксперименты UI не ломают остальной проект.
